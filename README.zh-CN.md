# Air Paint · 流漆

[English](README.md) | [简体中文](README.zh-CN.md)

手指蘸一点颜色。在空气里涂个开心。

一个用手指在空气中绘画的互动网页，支持摄像头手势识别、流动油漆和滴落效果，也可以用鼠标或触屏创作。

**[在线体验 Air Paint](https://limuma.github.io/Air-Paint/)**

## 功能

- 在镜像摄像头实景或粗糙墙面背景上绘画。
- 调节颜色、笔刷粗细、加水量、流动性、滴流长度和滴流粗细。
- 边画边流淌，在同一位置反复涂画会补充油量。
- 无需手势校准，也支持鼠标和触屏绘画。
- 局部擦除、撤销、清空画布以及 PNG 导出。
- 点击页头的 **EN / 中文** 切换界面语言，不清空画作或改变参数。浏览器允许存储时会记住选择。

## 开始使用

1. 在浏览器中打开[在线体验](https://limuma.github.io/Air-Paint/)。
2. 点击「开启摄像头」并允许摄像头权限；也可以直接用鼠标或手指在画布上拖动画画。
3. 使用手势时，保持整只手入镜、光线充足。
4. 刷新或关闭网页前，导出 PNG 保存作品。

## 参数说明

| 参数 | 作用 |
| --- | --- |
| 加水量 | 水越多，颜色越淡；水越少，颜色越浓 |
| 流动性 | 控制油漆流淌速度 |
| 画笔粗细 | 控制笔迹宽度 |
| 滴流长度 | 控制基础滴流长度 |
| 滴流粗细 | 控制液柱宽度 |
| 手部防抖 | 调节指尖跟随的平滑程度 |
| 橡皮大小 | 调节握拳擦除范围 |

## 手势操作

| 手势 | 动作 |
| --- | --- |
| 食指朝镜头伸出，其余手指收起 | 绘画 |
| 食指向上伸直，其余手指收起 | 绘画 |
| 五指张开 | 抬笔，移动不留痕 |
| 握拳并移动 | 以掌心位置进行擦除 |
| 手离开镜头 | 停笔 |

手指互相遮挡、部分手掌出框或光线不足时，识别可能不稳定。

## 本地运行

在仓库中点击 **Code → Download ZIP**，下载后解压。

应用打包在单个 `index.html` 文件中，无需安装 npm 依赖或执行构建。直接打开可尝试鼠标或触屏绘画；本地文件的摄像头访问取决于浏览器。

为了更可靠地使用摄像头，可在包含 `index.html` 的目录运行本地服务：

```sh
python3 -m http.server 3000
```

然后打开 [http://localhost:3000](http://localhost:3000)。

摄像头需要用户授权和浏览器支持的安全环境，如 HTTPS 或 localhost。普通 HTTP 局域网地址可能无法使用摄像头。

## 手机和平板

请使用 HTTPS 网页链接，不要从文件预览直接打开 HTML。iPhone、iPad 可尝试 Safari，安卓可尝试 Chrome。如果内置浏览器无法访问摄像头，请改用系统浏览器。

支持触屏绘画。摄像头识别与性能取决于设备和浏览器；本版本尚未在真实手机或 iPad 上验证。

## 技术实现

- HTML 与 CSS：界面结构和样式。
- JavaScript 与 Canvas 2D：笔刷、纹理、滴流动画和画面合成。
- MediaPipe Hands：手部关键点识别。

油漆效果属于程序化视觉模拟，不是完整流体物理求解。摄像头绘画是二维叠加：笔迹固定在画面坐标上，不支持三维空间锚定或真实物体遮挡。

## 隐私与联网

摄像头画面在浏览器本地处理，应用不会上传视频。

手势识别需要从第三方 CDN 加载 MediaPipe 代码和模型；资源未缓存时需要联网，不保证完整离线使用。

作品不会自动保存。刷新或关闭页面会清空画作，请使用 PNG 导出保存。
